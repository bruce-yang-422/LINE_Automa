# 公開圖片素材

建立：2026-10-05。狀態：已實作。

## 1. 用途

LINE 圖片訊息只接受**對外 HTTPS 網址**，不能直接傳本機檔案。外部 Python 腳本（營業數據圖表、天氣報告等）把產生的圖片放進 `line-oa-archive/media/`，LINE 服務就會以公開網址提供，腳本再用這個網址發送。

## 2. 資料夾與網址

```text
line-oa-archive/media/
├─ README.md          指向本文件（唯一會提交到 Git 的檔案）
├─ sales/             營業數據
└─ weather/           天氣報告
```

| 放在 | 對外網址 |
|---|---|
| `media/weather/today.png` | `https://<PUBLIC_BASE_URL>/media/weather/today.png` |
| `media/sales/2026-10-05-k3x9.jpg` | `https://<PUBLIC_BASE_URL>/media/sales/2026-10-05-k3x9.jpg` |

- `PUBLIC_BASE_URL` 為 `.env` 中的對外網址（例：`https://reports.example.com`），經 Cloudflare Tunnel 轉到本機 `127.0.0.1:18474`。
- 子資料夾可自行新增（例如 `media/promo/`），不需改程式或重新啟動服務。

## 3. 規則

| 項目 | 規則 |
|---|---|
| 格式 | PNG、JPG（`.png`、`.jpg`、`.jpeg`）；依檔頭驗證，副檔名不符的檔案回 404 |
| 大小 | 單檔 10 MB 以內（LINE 原圖上限） |
| 檔名 | 英數字、`-`、`_`、`.`，最多 100 字；不可用中文或空白 |
| 層級 | `media/` 本身或其下**一層**子資料夾；更深的路徑、`..`、捷徑連結一律 404 |
| 其他檔案 | `.txt`、`.csv` 等不提供 |
| 快取 | `Cache-Control: public, max-age=300`；網址後可加 `?v=日期`，不影響讀取 |

## 4. 安全注意

- **知道網址的任何人都能下載**，沒有登入檢查。營業數據等敏感圖片請用不易猜的檔名（日期加隨機字串），不要用固定名稱如 `daily.png`。
- 沒有目錄列表，無法從網址看出資料夾內有哪些檔案。
- 不再需要的圖片請由腳本自行刪除；系統不自動清理。
- 圖片內容不納入 Git（`.gitignore`：`media/*`，只保留 `media/README.md`）。

## 5. 快取與覆寫

LINE 會快取同一網址的圖片。同名覆寫後，已收到的聊天室或新發送仍可能顯示舊圖。要確保對方看到新圖：

- 每次產生新檔名（建議，例如 `2026-10-05-k3x9.png`），或
- 沿用檔名但在網址加 `?v=2026-10-05`。

## 6. 腳本範例

```python
from datetime import date
from pathlib import Path
import secrets
import shutil

MEDIA = Path(r"D:\Tools\LINE_Automation\line-oa-archive\media")
BASE_URL = "https://reports.example.com"  # 與 .env 的 PUBLIC_BASE_URL 相同

def publish(src: Path, folder: str) -> str:
    """把圖片放進 media/<folder>/，回傳 LINE 可用的公開網址。"""
    name = f"{date.today():%Y-%m-%d}-{secrets.token_hex(4)}{src.suffix.lower()}"
    target = MEDIA / folder / name
    target.parent.mkdir(exist_ok=True)
    shutil.copyfile(src, target)
    return f"{BASE_URL}/media/{folder}/{name}"

url = publish(Path("weather_report.png"), "weather")
# LINE 圖片訊息：{"type": "image", "originalContentUrl": url, "previewImageUrl": url}
```

發送時 `previewImageUrl` 建議用 1 MB 以內的圖片；原圖過大時可另存一張縮圖。

腳本自行呼叫 LINE Messaging API 所需的 token 填在 `line-oa-archive/.env`，每個 OA 一行 `LINE_CHANNEL_ACCESS_TOKEN_<basic ID>`，寫法與完整發送範例見[關鍵字訂閱](關鍵字訂閱.md)「6」。

訂閱名冊（要發給誰）見[關鍵字訂閱](關鍵字訂閱.md)。
