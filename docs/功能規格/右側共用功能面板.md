# 右側共用功能面板

2026-10-06 使用者指定：參考 VS Code 的工作台切版，以及 Obsidian 大綱、Photoshop 內容輔助面板的概念，套用整個後台。右側跟隨目前工作內容，主模組導覽留在左側，子頁切換留在上方。

- **檢查**：依「必須處理／需確認／資訊」顯示數量與逐項內容。值日生編輯班表時沿用目前班表的發布前檢查；通知設定顯示帳號、收件對象及預估缺漏；首頁顯示本月缺少班表或草稿未發布。其他頁面彙整既有頁面警告與驗證訊息。可定位的項目提供「查看」並跳到工作或對應區塊。
- **工具**：提供目前內容可用的儲存、CSV、預覽與新增等操作，沿用原有按鈕的權限、驗證與流程。右側不列主導覽或子分頁，也不重複分類與篩選列。
- **大綱**：依目前頁面的標題層級顯示區塊索引，點選定位內容；收合的內容區塊會展開。大綱用來閱讀與定位，不切換模組。
- **說明**：提供所在頁面的簡短操作順序。

右側內部分頁與外側功能列可切換或收合面板。操作面板只更新右側，不重建中間內容或清除尚未儲存輸入。編輯時即時顯示未儲存提示，切換頁面更新右側資料；不顯示先前班表的檢查結果。首次設定與聊天介面不顯示功能列。聊天介面同時隱藏面板與抽屜遮罩、移除右側預留空間；返回其他頁面恢復原面板選擇。

1600px 以上 PC 使用並排面板，預設 360px，可拖曳分隔線在 280–480px 間調整，也支援左右方向鍵及 Home／End。21:9 螢幕保留可調寬度；值日生首頁月份卡片平均分配剩餘寬度至區塊右緣，空間較窄時換列。

較窄 PC 使用抽屜；1100px 以下改為右下角工具列與抽屜。支援背景關閉、Esc、鍵盤焦點限制及關閉後回到入口。原有對話框開啟時由對話框接管鍵盤。面板內容獨立捲動。

功能列使用既有圖示與低飽和色彩；警告分級同時以文字與數量表達。資料只使用既有授權 API 的回傳結果與目前頁面，不新增資料表，也不執行額外通知發送。

PC 固定工作台框架：滿版上方工具列、左側主導覽、中間工作區、右側輔助面板、底部狀態列。中間與右側各自捲動；底部持續顯示就緒／未儲存狀態。手機維持頁面捲動與抽屜操作。
