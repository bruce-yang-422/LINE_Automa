# 表單與回覆管理規格

建立：2026-10-05。狀態：**構想／待實作**。本文件記錄預定行為，不表示目前系統已提供功能。

## 1. 目的與範圍

建立獨立的「表單與回覆」模組，整合既有組織、LINE OA、聯絡對象、帳號權限與訊息發送功能。適用於公司團購、旅遊意見詢問、班級家長回饋、活動參加意願等日常用途。

第一版採用自建 HTML 表單，由本平台直接保存答案。LINE 負責發送填寫連結及提醒；不依賴 LINE 原生問卷功能。Google 表單等外部工具串接及聊天逐題問答保留為後續擴充。

不要求填寫者登入後台、登入 LINE 或交叉驗證身分。每份問卷使用同一個可分享連結，允許轉傳及同一人多次填寫；不追蹤收件人是否已填，不把回覆歸屬到 LINE 聯絡人。姓名、電話等若有需要，由題目詢問並視為填寫者自述。

## 2. 使用流程

1. 乙級或丙級人員建立表單，設定題目與截止時間，預覽後發布。
2. 選擇該 OA 的聯絡人，發送同一份問卷分享連結。
3. 使用者在手機網頁填寫；伺服器驗證欄位並保存答案。
4. 保存成功後建立獨立回覆，提供該筆回覆專屬修改連結；後台可查看答案與提交時間。
5. 操作人員選擇可接收訊息的聯絡人，手動發送一般提醒（若已填寫，請忽略）。
6. 截止前可透過回覆專屬修改連結修改答案；問卷分享連結永遠開啟空白問卷。停止收件後顯示停止或截止說明。

開啟連結不建立回覆；只有成功保存答案才增加回覆數。回覆數不代表填寫人數，通知紀錄不代表是否完成。

## 3. 後台管理

### 3.1 表單維護

- 新增、編輯、複製、預覽及刪除表單。
- 設定名稱、說明、題目順序、必填欄位、選項、截止時間及送出後提示文字。
- 表單狀態：草稿、收件中、停止收件。設定截止時間後由伺服器判斷是否可提交。
- 草稿不接受提交；停止收件可在調整截止時間後重新開放。
- 以範本提供團購、旅遊意見及家長回饋，不為每種用途建立不同程式或資料表。

### 3.2 表單設計器與題型

後台提供類似 Google 表單操作方式的表單設計器，乙、丙級可自行組合題目，不需編寫 HTML 或修改腳本。此處指本平台的設計目標，不要求串接 Google 表單服務。

- 以題目卡片編輯標題、說明、題型、選項與必填開關。
- 支援新增、複製、刪除與拖曳排序，並提供上下移動按鈕供手機及鍵盤操作。
- 選項可新增、修改、移除及排序；單選、多選可開啟「其他」並讓填寫者補充文字。
- 支援分區標題與說明，將團購品項、聯絡資訊等內容分組。分區不提供題型選單，也不收集答案；新增分區預設「從此分區開始新頁」，可取消以作為同頁標題。既有未設定換頁的分區維持同頁，第一個分區不產生空白頁。
- 問卷預設一頁多題，透過分區指定換頁；提供上一頁、下一頁、頁碼及最後一頁提交。本頁答案驗證通過才前進，返回不驗證且保留所有輸入；正式提交由伺服器驗證整份答案，錯誤時切到該題所在頁。草稿保留頁碼與非附件答案，未提交附件仍須重傳。後台預覽採相同換頁方式。
- 建置介面置中最大寬度 960px，預覽置中最大寬度 720px，手機隨螢幕縮小。卡片上方顯示題目／分區編號及類型，標題為主要欄位、題型為次要欄位，排序／複製／刪除集中於卡片底部。
- 每題可展開「答案驗證」，選擇是否啟用及設定條件、錯誤提示。
- 提供編輯與填寫預覽，預覽套用實際的必填及驗證規則，但不建立正式回覆。

| 題型 | 用途及設定 |
|---|---|
| 短文字 | 姓名、電話、Email；可選格式與長度驗證 |
| 段落文字 | 備註、自由意見；可限制字數 |
| 單選 | 一組選項最多選一個；可加「其他」 |
| 多選（核取方塊） | 可選多個答案；可加「其他」及限制選取數量 |
| 下拉選單 | 選項較多時使用，最多選一個 |
| 數字／數量 | 訂購數量、參加人數；可設定整數、小數及數值範圍 |
| 日期 | 活動日期等；可設定允許的日期範圍 |
| 時間 | 集合時間、偏好時段 |
| 評分量表 | 滿意度、推薦程度；可設定分數範圍及兩端說明 |
| 附件上傳 | 可設定允許格式、單檔大小、檔案數量；圖片上傳完成後顯示縮圖 |

以上題型納入第一版設計範圍。矩陣題與依答案跳題另列後續擴充，不宣稱第一版完整複製 Google 表單所有能力。

題目有固定識別碼，改名稱或排序不改識別碼。已有回覆後，刪題及修改選項不得使既有答案失去解讀依據；需保留提交時的題目及選項快照，並在變更時提示影響。新增必填題不回溯將舊回覆判為未完成。

### 3.2.1 可選的答案驗證

「必填」與「答案驗證」是獨立設定。預設不開啟額外格式驗證；管理者可逐題啟用，填寫者看到適當的格式提示。

| 驗證 | 可設定條件 |
|---|---|
| 電話格式 | 選擇台灣手機、台灣市話或一般國際電話；市話可允許分機。接受常見空格及連字號，不一律套用手機十碼規則 |
| Email 格式 | 檢查一般 Email 結構，不寄驗證信、不要求確認信箱所有權 |
| 文字長度 | 最少／最多字數，自訂提示 |
| 數字 | 整數或允許小數、最小／最大值 |
| 多選數量 | 至少、最多或恰好選幾項；「其他」算一項 |
| 日期範圍 | 不早於／不晚於指定日期 |

- 電話與 Email 是短文字題的格式選項，可關閉；電話一律以文字保存，保留開頭的 `0` 與 `+`。
- 選填題空白可提交，即使啟用格式驗證；有填答案才檢查格式。必填題空白或只有空白字元不能提交。
- 關閉額外驗證仍須遵守題型基本結構：單選不能傳多個答案，選擇題答案必須是目前有效選項，數字題仍須是數值。
- 若「其他」被選中，其補充內容需填寫。多選至少數量與最多數量不得互相矛盾，不能超過可選項數。
- 前端即時提示與伺服器提交驗證使用相同規則；未通過時指出對應題目，保留全部輸入。
- 格式驗證不等於身分驗證，不增加簡訊 OTP、LINE 登入或其他交叉驗證要求。
- 平台統一的資料大小限制仍適用，不因關閉題目驗證而接受無限長內容。

### 3.2.2 附件格式與圖片預覽

附件是可重複使用的題型，每題可獨立設定必填、允許格式、最多檔案數、單檔大小及該題附件總大小。設定不得超過平台統一上限；填寫頁在選檔前顯示限制。

管理者可多選格式群組，再細選副檔名；不提供未經限制的「所有格式」。允許格式清單如下：

| 格式群組 | 可選格式 |
|---|---|
| 圖片 | JPG／JPEG、PNG |
| PDF | PDF |
| 文書：現代 Microsoft Office | DOCX、XLSX、PPTX |
| 文書：舊版 Microsoft Office | DOC、XLS、PPT |
| 文書：OpenDocument（LibreOffice／OpenOffice） | ODT、ODS、ODP |
| 純文字／資料 | TXT、CSV |
| 壓縮檔 | ZIP、RAR |
| 音訊 | MP3、WAV |
| 影片 | MP4、MOV |

圖片不支援 WebP、GIF、HEIC／HEIF；影片不支援 WebM；音訊不支援 M4A。設計器不提供這些選項，後端也拒絕直接上傳這些格式。文書格式可個別勾選，支援上傳與下載，不要求伺服器安裝 Office 或將文書轉成圖片預覽。

- 副檔名大小寫不影響判斷。網頁選檔提示與後端允許清單一致，後端檢查大小、格式及可辨識的檔案內容，不只相信檔名或瀏覽器宣告。
- 格式、大小及數量限制屬附件基本規則，不受文字題的「答案驗證」開關影響。
- 可逐檔查看上傳中、完成、失敗狀態，並移除、替換或重試；數量限制包含已保存與新上傳附件。
- 選到圖片可先顯示本機預覽；上傳成功後必須顯示伺服器產生的預覽縮圖，並提供放大查看。
- JPG／JPEG、PNG 縮圖依圖片比例顯示，不拉伸；修正方向資訊，縮圖不包含定位等非必要中繼資料。
- 非圖片顯示格式圖示、原始檔名、大小及下載操作；格式不支援預覽時仍可查看檔案資訊。
- 附件題必填時至少有一個上傳成功的檔案才能送出；有上傳尚未完成或失敗時，不默默忽略檔案而完成提交。
- 修改回覆時顯示既有附件及縮圖；移除既有附件在成功保存修改後才生效，提交失敗不刪除原附件。
- 後台答案詳細頁也顯示圖片縮圖與下載操作，遵守表單的組織、OA 及角色範圍。
- 公開填寫者只能存取本回覆草稿或持有修改碼的回覆附件；不沿用可任意公開存取的圖片網址，不允許指定伺服器檔案路徑。
- 未提交的暫存上傳設定清理期限；刪除表單、替換或移除附件後清理不再引用的檔案與縮圖，避免堆積。
- CSV 匯出附件名稱與附件識別碼，不內嵌二進位檔案，也不匯出後台登入憑證或分享碼或回覆修改碼。

### 3.3 發送與回覆

- 選擇收件人、預覽訊息、確認後發送；沿用既有發送授權與模組啟用限制。
- 同一問卷的通知連結相同，發送及提醒紀錄與答案分開保存。
- 發送及提醒沿用 `send_jobs`／`send_deliveries`。僅 LINE 明確接受後更新通知／最後提醒時間；失敗可手動預覽確認後重試，結果不明不自動重送。實際發送前重新檢查授權、模組、收件狀態與截止時間。
- 顯示通知收件人數、回覆筆數與發送成功／失敗；不提供收件人已填／未填統計。
- 同一人可新增多份回覆；同一提交識別碼重送不增加筆數，使用修改連結更新同一份回覆。
- 回覆清單依問卷、填寫內容／回覆代號搜尋，按首次提交或最後更新時間篩選與匯出；日期以台北時間判斷且包含結束當日，不宣稱回覆對應哪位 LINE 聯絡人。
- 詳細頁按各筆提交快照解讀題目與選項，改名或刪題後仍可閱讀；附件以授權請求提供縮圖、放大及下載。
- CSV 匯出目前篩選範圍全部回覆，以穩定題目 ID／題型合併快照欄位，保留曾用欄名及刪題內容。使用 UTF-8 BOM，正確處理逗號、引號、換行；公式前綴及電話欄位加單引號作文字保護。只輸出回覆代號、提交／更新時間、答案及附件名稱／ID，不含分享碼、修改碼、提交識別碼或登入憑證，匯出留下稽核。
- 一般提醒可發給選取且可接收訊息的聯絡人，不依回覆排除收件人；提醒包含「若已填寫，請忽略」。
- 刪除表單需確認並顯示通知與回覆數；分享及修改連結失效，保留操作紀錄。

## 4. 帳號權限

角色命名與資料範圍依 [權限與角色規格](權限與角色規格.md)。以下為本模組的預定權限，實作時需同步主權限文件。

| 功能 | 甲級：平台管理員 | 乙級：管理員 | 丙級：操作人員 | 丁級：協作人員 |
|---|---|---|---|---|
| 查看表單及回覆 | 唯讀，依既有稽核規範 | 所屬組織全部 OA | 被授權 OA | 被授權 OA，唯讀 |
| 新增、編輯、複製、刪除 | 不可 | 可 | 可 | 不可 |
| 發布、停止及重新開放收件 | 不可 | 可 | 可 | 不可 |
| 發送問卷連結、一般提醒 | 不可 | 可 | 可 | 不可 |
| 匯出回覆 CSV | 不可 | 可 | 可 | 不可 |

乙、丙級皆可維護範圍內的表單，不限本人建立的表單。後端同樣檢查組織、OA 與角色，不僅隱藏按鈕。一般 LINE 填寫者不屬於後台角色。

## 5. 問卷分享連結與回覆修改連結

問卷網址：`https://平台網域/forms/表單代號?token=問卷分享碼`。
回覆修改網址：`https://平台網域/forms/表單代號?token=問卷分享碼&edit=回覆修改碼`。

- 分享碼由伺服器隨機產生，只對應問卷，網址不含電話、Email 或 LINE ID；同份問卷可自由轉傳。
- 提交只依分享碼查詢問卷所屬組織與 OA，不接受聯絡人身分欄位。
- 分享連結不能查看既有回覆；同一瀏覽器有未提交草稿時恢復欄位，沒有草稿時顯示空白問卷。
- 每份填寫頁取得隨機提交識別碼；重複提交同一識別碼不新增回覆，不以身分、IP 或瀏覽器限制再次填寫。
- 提交成功提供隨機回覆修改碼，只授權該份回覆；修改連結可查看答案，填寫者需保存且不應分享。不保存修改連結則無法自行找回回覆。
- 手機優先；失敗保留輸入。修改保留首次提交時間、更新最後修改時間，並檢查問卷與回覆版本衝突。
- 文字與選項每次變更即保存至同一瀏覽器的本機草稿，關閉後重新開啟可接續；草稿按問卷／修改連結隔離，不建立正式回覆。未提交附件不即時保存，重開需重新選取上傳，已提交附件仍在修改頁顯示。
- 提供「重新填寫（一鍵清除）」清除本機草稿並開啟空白新回覆，不刪除已提交回覆。提交成功清除草稿；伺服器回覆已更新時載入最新答案，不以舊草稿覆寫。瀏覽器禁止本機保存時明確提示。
- 無效連結、表單刪除、草稿、停止收件及截止均提示；使用既有 HTTPS 入口及獨立 CSP，不使用後台登入憑證。

## 6. 資料結構構想

規劃共用資料表，不因團購、旅遊或其他用途增加表單專屬資料表。實際欄位與索引在實作前確認。

| 資料表（暫名） | 主要內容 |
|---|---|
| `forms` | 表單 ID、組織、OA、名稱、說明、題目設定 JSON（題目／選項固定 ID、題型、排序、必填、其他選項、驗證開關／條件／提示）、狀態、截止時間、建立／修改人及時間 |
| `form_public_links` | 每份問卷唯一的隨機分享碼 |
| `form_notifications` | 通知 ID、問卷、OA 聯絡人、發送及最後提醒時間，不保存答案或個人邀請碼 |
| `form_submissions` | 回覆 ID、問卷、提交識別碼、唯一修改碼、答案 JSON、提交時題目快照、首次提交與最後更新時間，不保存收件人 ID |
| `form_upload_drafts` | 隨機回覆草稿權限碼、問卷、可選的既有回覆 ID、建立時間；修改碼驗證後才建立對應回覆的草稿 |
| `form_attachments` | 附件 ID、問卷、題目、草稿、可選的正式回覆 ID、原始檔名、副檔名、大小、受控原檔／縮圖檔名、暫存／正式／待清理狀態與建立時間 |
| `form_send_jobs` | 既有發送工作 ID、問卷 ID、首次發送／一般提醒類型、文案；發送結果仍由既有工作與逐對象紀錄保存 |

回覆直接屬於問卷；每個提交識別碼在同一問卷唯一，重送不新增。修改碼唯一，修改以更新方式保存。問卷與 OA 資料範圍依 `forms` 判斷，回覆依問卷及提交時間建立索引。既有邀請資料轉為通知紀錄；舊回覆保留內容／快照／時間並解除收件人綁定，舊個人邀請碼失效。

發送結果與操作紀錄優先沿用平台既有機制，不另外複製發送系統。答案不回寫聯絡人的電話或備註，除非日後另外設計明確的同步功能。

附件原檔與縮圖存於 `line-oa-archive/private/form-attachments/` 非公開目錄，答案 JSON 只保存附件識別碼。以共用附件表處理回覆草稿／修改權限，讀取不接受檔案路徑。圖片經 Pillow 驗證、修正方向並產生等比例且不含 EXIF 的縮圖；其他格式依已確認的檔頭／ZIP 結構／文字解碼規則檢查，不解壓內容。相同上傳識別碼重試不重複保存檔案。24 小時暫存期限與容量上限集中於 `limits.py`；替換／移除在成功保存回覆後標記待清理，排程 `tick()` 回收原檔與縮圖，刪除問卷亦回收檔案。以上共用表為核心表單結構，不因問卷用途增加專屬資料表。

## 7. 第一版驗收方向

- 乙、丙級可在授權範圍完成新增、修改、發布與刪除；越權存取被後端拒絕。
- 同一份問卷連結可發送與轉傳給多人；各次填寫建立獨立回覆，分享連結不顯示其他答案。
- 提交與修改能正確保存；同一提交識別碼重送不新增，同一人重新填寫可新增回覆。
- 開啟不建立回覆；通知與回覆分開統計，一般提醒不依回覆排除收件人。
- 發送失敗可辨識與重試，不顯示為成功通知。
- 截止與停止收件由伺服器判斷，手機能順利填寫及閱讀提示。
- 題目修改後既有答案仍可解讀；刪除表單後連結不能繼續提交。
- 匯出中文、逗號、換行等內容的 CSV 可正確閱讀。
- 管理者可透過設計器新增、複製、排序及修改各題型，不需改程式。
- 電話與 Email 驗證可逐題開關；同一份表單可同時有驗證與不驗證的文字題。
- 選填空白可送出；必填、格式及多選數量錯誤都有明確提示，伺服器同樣拒絕不合法答案。
- 電話保存後保留前導零及國際冠碼；單選、多選及「其他」答案可正確保存、回填與匯出。
- 附件可逐題限制格式、大小及數量，超限與偽裝格式在後端被拒絕。
- 圖片上傳成功後，填寫頁與後台皆可看到縮圖及放大預覽；非圖片顯示檔名、大小與下載操作。
- 修改答案時附件可替換或移除，失敗不丟失原附件；未完成上傳不會被視為成功提交。
- 未持有該回覆草稿或修改碼者不能讀取附件，刪除及暫存清理可回收原檔與縮圖。

問卷設計器操作補充：右側「工具」提供題目與分區的排序清單，支援拖曳插入、上移／下移與點選跳到編輯卡片；移動後即時更新題目編號、分區與頁碼，儲存題目後才正式生效。拖曳提供浮影、來源淡化及插入位置提示，換位提供滑動與短暫標示；減少動態效果設定停用滑動。開啟其他選項後，在選項編輯區顯示「其他」及補充文字輸入框示意。

問卷說明內容：除題目與分區，提供獨立「說明內容」項目，可選文字、圖片／圖文說明或 YouTube 影片；標題與說明文字選填，文字類至少一項非空，圖片類必須有圖片，影片類必須有有效單支 YouTube HTTPS 連結。支援純圖片或純影片，可與題目／分區一起排序、複製、刪除，隨分區換頁；不接受答案、不設必填、不進 CSV 答案欄位，但計入每份問卷項目上限。
圖片使用既有上傳圖庫，限定 8 MB JPG／PNG，正規化為 PNG 並移除來源中繼資料；讀取與儲存驗證所屬 OA／組織，公開讀取只允許目前問卷引用的圖片且需有效問卷分享憑證，保留 no-store 與 no-referrer。YouTube 只接受官方 HTTPS watch、youtu.be、embed、shorts 單支影片連結，伺服器解析影片 ID，公開填寫頁使用 youtube-nocookie 內嵌播放器（不自動播放）。後台不擴大 CSP，預覽使用影片卡片及外開 YouTube 連結。
