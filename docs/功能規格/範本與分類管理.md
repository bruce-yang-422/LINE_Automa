# 範本與分類管理規格與 UI/UX 說明文件（低認知負荷·使用者導向版本）

> **核心設計哲學**  
> **「不要求使用者理解『範本系統』，只需要知道『我要做什麼』。」**  
> 全面朝「低認知負荷、零教學 30 秒上手、防呆且容易復原」的方向打造，將底層複雜的資料治理架構隱藏於直覺的任務引導之後。

---

## 1. 設計願景與重構原則（Vision & UX Principles）

### 1.1 傳統管理後台 vs 使用者導向思維

| 維度 | 舊思維（管理後台／資料治理導向） | 新思維（低認知負荷／使用者任務導向） |
|---|---|---|
| **核心提問** | 「你要管理哪一個 Template Pack 與 Taxonomy？」 | **「你現在想做什麼？」** |
| **首頁呈現** | 複雜 Master-Detail 雙欄、左側一堆 Pack、右側案件記事混排 | **極簡首頁**：搜尋框＋兩顆大任務按鈕＋常用推薦卡片 |
| **新增流程** | 一張長表單塞滿專業欄位（Priority, Category ID, Tags JSON） | **3 步引導精靈（Step-by-Step Wizard）**，每步只做一件事 |
| **結構術語** | Template Pack、Taxonomy、Entity Reference | **「我的範本」、「範本群組」、「分類與標籤」**（人話呈現） |
| **色彩角色** | 賦予 10 種顏色獨立業務意義（需記憶顏色代碼） | **文字為主，顏色為輔**（如 `🔴 緊急`），色弱與新手皆無障礙 |
| **前線套用** | 新增記事 → 點範本 → 跳出二層 Modal → 選擇 Pack → 套用 | **表單頂部即時推薦膠囊**，一鍵點選直接填入，零多層彈窗 |
| **防呆機制** | 頻繁跳出「您確定嗎？」的阻斷式確認窗 | **優先提供「↺ 復原（Undo）」**，降低操作心理壓力 |

### 1.2 八大低認知負荷 UI 準則（8 Golden UI Rules）

1. **一頁一目的**：每個畫面與對話框僅專注於一個主要任務。
2. **一個主要行動點（Single Primary CTA）**：每頁最多一個高亮 Primary Button，引導直覺下一步。
3. **全面使用大白話（Human-readable Language）**：徹底剔除系統術語（不出現 Pack、Taxonomy、Payload 等）。
4. **重要資訊文字優先**：不單靠 Icon 或顏色傳達關鍵狀態，一律伴隨文字標籤。
5. **漸進式揭露（Progressive Disclosure）**：90% 使用者只需前三層功能，進階設定預設收合。
6. **立即反饋與即時預覽（Immediate Feedback）**：編輯過程中即時呈現「卡片完成預覽」。
7. **允許反悔與無痛復原（Undo-first Approach）**：以非阻斷式 Toast +「復原」按鈕取代繁瑣的確認窗。
8. **降低記憶負擔（Recognition over Recall）**：系統主動列出選項與推薦，絕不要求使用者背誦規則。

## 2. 重新定義的資訊架構（Information Architecture）

底層資料庫繼續完整保留 `template_packs`、`case_templates`、`note_templates`、`categories`、`tags` 的多租戶結構，但前端介面全面轉換為使用者心智模型：

```text
範本與分類
│
├── 🏠 首頁（任務導航、全局搜尋、常用推薦、最近使用）
│
├── 📋 我的範本（我平常會用到的標準內容）
│   ├── 全部範本
│   ├── 案件範本（報修、客訴、詢價、交辦任務）
│   └── 記事範本（客戶來電、現場場勘、會議備忘）
│
├── 🏷️ 分類與標籤（整理資料的工具）
│   ├── 分類（單選：這件事「主要是哪一類」）
│   └── 標籤（多選：還有「哪些特徵」）
│
└── ⚙️ 進階設定（漸進式揭露，管理員專用）
    ├── 範本群組管理（原 Template Packs）
    ├── 系統標準範本庫
    └── 啟用／停用與權限治理
```

## 4. 人話定義：「分類」與「標籤」的極簡邊界

使用者經常困惑「分類」與「標籤」的差別，介面以一句話清楚定位：

```text
┌───────────────────────────────────────────────────────────────┐
│  📂 分類（只能選 1 個）                                       │
│  用途：「這件事情主要是哪一類？」                             │
│  範例：客戶服務、工程工務、商務業務、學校教務、政策民意       │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│  🏷️ 標籤（可以選很多個）                                     │
│  用途：「這件事情還有哪些特徵與備註？」                       │
│  範例：#已報價、#待主管確認、#需二次回訪、#VIP客戶、#現場勘查  │
└───────────────────────────────────────────────────────────────┘
```

## 5. 無障礙色彩原則：文字為主，顏色為輔

視覺色彩能增進辨識，但不強迫使用者背誦色碼：

```text
【推薦呈現】
🔴 緊急優先      🟠 重要處理      ⚪ 一般進度      🟢 處理完畢

【規範】
1. 任何帶顏色的徽章，文字必須完整顯示（禁止只有一顆紅點而無文字）。
2. 背景色維持 Apple HIG 14%~20% 柔和透明度，文字對比度達 WCAG 2.1 AA（> 4.5:1）。
3. 色彩點選器提供即時縮放與 Focus 環，支援鍵盤 Tab 與方向鍵選取。
```

## 6. 前線極簡套用流程（Zero-Modal in Modal）

徹底解決「在 Modal 裡面再開 Modal 找範本」的糟糕體驗：

```text
+--------------------------------------------------------------------+
|  新增對話記事                                                      |
|                                                                    |
|  ⚡ 常用範本快速帶入：                                             |
|  [ 📝 商務洽談 ]   [ 📝 現場場勘 ]   [ 📝 客戶來電 ]   [ 更多範本… ]|
|                                                                    |
|  記事標題（選填）                                                  |
|  [ 客戶洽談採購規格備忘                                          ] |
|                                                                    |
|  記事分類                                                          |
|  [ 商務業務 ▾ ]                                                    |
|                                                                    |
|  記事標籤                                                          |
|  [ 已報價 x ] [ 需二次回訪 x ]                                     |
|                                                                    |
|  記事內容                                                          |
|  +--------------------------------------------------------------+  |
|  | 1. 客戶採購需求：50 台設備                                   |  |
|  | 2. 報價條件：含稅含運                                         |  |
|  | 3. 約定回訪時間：週五下午                                     |  |
|  +--------------------------------------------------------------+  |
|                                                                    |
|  [ 取消 ]                                           [ 儲存記事 ]   |
+--------------------------------------------------------------------+
```
- 使用者點擊頂部的 `[ 📝 商務洽談 ]` 膠囊按鈕，表單**瞬間帶入**標題、分類、標籤與內容大綱，並跳出 `✓ 已套用「商務洽談」範本` 微提示，**無需二次彈窗**。

## 7. 非阻斷式防呆：優先提供「復原（Undo）」

```text
+--------------------------------------------------------------------+
|  🗑️ 範本「設備故障報修流程」已刪除。               [ ↺ 復原 (5s) ] |
+--------------------------------------------------------------------+
```
- 刪除範本或分類時，系統優先執行軟刪除並於畫面下方彈出 Toast 提示與「復原」按鈕（停留 5 秒）。
- 使用者如為誤觸，只需點擊「復原」即可毫秒級復原，徹底消除操作恐懼。
- 僅在涉及「跨帳號永久清除」等不可逆操作時，才彈出具體說明後果的對話框（禁止只問「您確定嗎？」）。

---

## 8. 漸進式揭露（Progressive Disclosure）：將 Pack 降級為進階群組

- **90% 日常使用者**：在「我的範本」中只看到清晰的卡片清單與「建立範本」按鈕。
- **10% 企業管理員**：點擊右上角「⚙️ 進階範本群組」才展開 Pack 分組、多 OA 派發與匯出/匯入功能。

---

## 9. 總結：核心改版前後對照

```text
【過去】
使用者必須先學會：什麼是 Template Pack？什麼是 Note Taxonomy？怎麼複製 Pack？
                    ⬇
【現在】
使用者只需回答：「我想做什麼？新增範本？整理分類？還是直接套用？」
30 秒內不需看任何說明文件即可直覺完成！
```
