| 選單 | 平台管理員 | 管理員 | 操作／協作人員 |

管理群組沒有任何可見項目時，隱藏「管理」標題。

## 各角色看到的選單

| 選單 | 平台管理員 | 管理員 | 操作人員 | 協作人員 |
|---|---|---|---|---|
| 工作空間整組 | 隱藏 | ✓ | ✓ | ✓ |
| 建立發送 | — | 組織啟用訊息模組時 | 同左 | 同左（目前仍顯示，後端拒絕送出） |
| 個人化設定 | ✓ | ✓ | ✓ | ✓ |
| 管理 | 組織、LINE OA | LINE OA、人員與權限、組織設定 | — | — |

- 平台管理員登入後只停在「組織」、「LINE OA」或「個人化設定」，也不顯示工作台搜尋。
- 尚未選定可用的 LINE OA 時，只能開啟 OA 一覽、範本與分類管理、個人化設定與管理頁，其餘頁面導向「LINE OA」（平台管理員導向「組織」）。

## 頂端列

| 項目 | 說明 | 顯示條件 |
|---|---|---|
| OA 切換 | 顯示目前 OA，點選切換或回到 OA 一覽 | 全部 |
| 搜尋工作台 | `Ctrl／⌘ K` 搜尋頁面與聯絡對象 | 平台管理員除外 |
| 重新整理 | 重新讀取資料 | 全部 |
| 我的帳號 | 顯示名稱、修改密碼、登入裝置 | 全部 |
| 切換視角 | 以其他人員的視角預覽 | 平台管理員、管理員 |
| 登出 | — | 以密碼登入（含對外網址）時 |

視角預覽中，頁面上方顯示預覽橫幅與「返回原帳號」。
