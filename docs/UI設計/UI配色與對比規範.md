# UI 配色與對比規範

更新：2026-09-30。以使用者提供的綠色相近色為方向，保留指定的 `#00B900` 為主色，其餘降低飽和度，避免大面積鮮亮綠色。

## 主色與衍生色

| 變數 | 色碼 | 用途 |
| --- | --- | --- |
| `--color-1` | `#00B900` | 主要按鈕、連線狀態標記 |
| `--color-2` | `#24372A` | 森林綠文字、深色操作、圖示 |
| `--color-3` | `#7C916C` | 苔綠提示邊框、裝飾強調 |
| `--color-4` | `#A7C5A0` | 灰綠選取標記、輔助操作 |
| `--color-5` | `#E1EBDD` | 淺鼠尾草綠選取底、提示底 |

主要按鈕使用 `#18271D` 深色文字搭配 `#00B900`。背景 `#F4F6F2`、卡片 `#FEFFFC`、次要文字 `#4E6353`。全站僅提供亮色介面，不提供深色模式。

色票在 `line-oa-archive/web/admin.css` 的 `:root`，元件規則在 `workspace-theme.css`，密集版面在 `density.css`。舊的 `--orange` 變數為既有元件相容別名，現在對應苔綠，不再使用橘色。現有 Logo 圖檔與使用者上傳圖片保持原有內容。

## 記事分類與標籤色（Apple 系統色）

記事分類與標籤使用 Apple 系統色作為辨識輔助，膠囊以淺色底＋同色文字呈現（文字為主、顏色為輔，不能只靠顏色傳達意義）：

| 用途 | 色碼 |
| --- | --- |
| 一般備忘 | Gray `#8E8E93` |
| 商務往來、已報價 | Blue `#007AFF` |
| 問題處理、技術支援 | Orange `#FF9500` |
| 待辦交接、交接事項 | Green `#34C759` |
| 急件優先 | Red `#FF3B30` |
| 待確認 | Yellow `#FFCC00` |
| 待追蹤 | Teal `#30B0C7` |
| 需回覆 | Purple `#AF52DE` |
| 合約文件 | Indigo `#5856D6` |

淺色系（Yellow、Teal、Green 等）做為文字色時對比可能不足，標籤文字需加深或改用深色文字，以維持 4.5:1。完整定義見[對話記事本管理規格](../功能規格/對話記事本管理規格.md)「7.1.2」、「7.2.2」。

## 可讀性

一般文字至少 4.5:1；本專案對小字、placeholder、停用控制項均以 4.5:1 檢查。按鈕不能只為淡化而降低整體透明度。選取、警示、錯誤亦須有文字或邊框標記；圖片分區編號使用不透明背景。
